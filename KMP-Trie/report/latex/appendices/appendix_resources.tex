\chapter*{PHỤ LỤC B. HƯỚNG DẪN CHẠY LẠI KẾT QUẢ}
\addcontentsline{toc}{chapter}{PHỤ LỤC B. HƯỚNG DẪN CHẠY LẠI KẾT QUẢ}

Toàn bộ số liệu trong Chương 6 có thể sinh lại bằng các lệnh dưới đây,
chạy từ thư mục gốc của đồ án. Mọi đường dẫn đều tương đối nên không phụ
thuộc máy cụ thể.

\begin{quote}
\# 1. Kiểm thử --- kỳ vọng: 276 passed

python -m pytest tests/ -q

python -m pytest -\/-doctest-modules src/ tests/baseline.py -q

\# 2. Sinh dữ liệu (seed mặc định 20260728)

python scripts/gen\_data.py \# đầy đủ, khoảng 20 MB

python scripts/gen\_data.py -\/-quick \# bộ nhỏ để thử nhanh

\# 3. Chạy thực nghiệm và vẽ biểu đồ

python scripts/run\_benchmark.py -\/-repeat 7

python scripts/plot\_results.py

\# 4. Demo

python -m demo.cli

python -m demo.web \# rồi mở http://localhost:8000
\end{quote}

Tôi đã kiểm tra tính tái lập bằng cách sao chép kho mã sang một thư mục
sạch, xóa toàn bộ thư mục data và results, rồi chạy lại đúng các lệnh
trên. Bộ test vẫn cho 276 passed, và dữ liệu sinh ra có mã băm SHA-256 trùng
khớp với bản gốc, xác nhận rằng seed cố định thực sự cho kết quả tái lập
được.
